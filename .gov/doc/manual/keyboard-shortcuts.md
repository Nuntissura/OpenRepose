# Keyboard shortcuts

## File / export

- **Ctrl+O** — Open portrait.
- **Ctrl+E** — Export single (current yaw → `<slug>_yaw_<bin>.json` + `.png`).
- **Ctrl+Shift+E** — Export 13-angle batch.
- **Ctrl+Q** — Quit (close to tray if `--tray` enabled, else exit).

## Calibration tab

- **Mouse wheel** — zoom anchored under cursor.
- **Spacebar + left-click + drag** — pan (Photoshop convention).
- **Left-click** — place marker for the currently-selected dropdown item (no-op if `— pick one —` is active).
- **Left-click + drag** on an operator marker (Overview mode or matching single marker) — move that marker.
- **Right-click** on an operator marker — delete it.

## Toolbar (top)

- **Yaw bin dropdown** — snap to one of the 13 standard angles.
- **Yaw slider** — free-form yaw `[-90, +90]` integer degrees.
- **Direction arrow** (`→` / `←`) — visual hint for the current yaw direction.
